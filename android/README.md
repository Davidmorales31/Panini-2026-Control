# Android Wrapper

Esta carpeta queda reservada para el proyecto Android generado por Capacitor.

Flujo:

```powershell
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap add android
npx cap sync android
npx cap open android
```

No se versiona un APK compilado aqui porque depende del Android SDK local y de firma.
